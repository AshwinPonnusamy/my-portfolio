# Professional Portfolio Site

A modern, high-performance portfolio website built with React 19, Tailwind CSS 4, and Framer Motion. This project showcases a clean, glassmorphic design with smooth animations and a fully responsive layout.

## 🚀 Technologies Used

- **React 19**: Latest React features for optimal performance.
- **Vite 7**: Ultra-fast build tool and development server.
- **Tailwind CSS 4**: Modern utility-first CSS framework with native support for CSS variables and enhanced performance.
- **Framer Motion**: Powering fluid micro-animations and section transitions.
- **Lucide React**: Beautifully crafted open-source icons.
- **React Router Dom**: Client-side routing for seamless navigation.

## ✨ Key Features

- **Glassmorphism UI**: Sleek, modern design with translucent elements.
- **Responsive Design**: Optimized for all screen sizes, from mobile to ultra-wide displays.
- **Immersive Sections**:
  - **Hero**: Dynamic landing with animated floating elements.
  - **About**: Professional overview and story.
  - **Portfolio**: Interactive gallery showcasing projects.
  - **Services**: Detailed breakdown of expertise.
  - **Achievements**: Visual display of milestones and certifications.
  - **Testimonials**: Social proof with customer feedback.
  - **Contact**: Functional contact form with validation.

## 🛠️ Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone [repository-url]
   ```
2. Navigate to the project directory:
   ```bash
   cd my-portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## 📂 Project Structure

```text
src/
├── assets/          # Images, icons, and static files
├── components/      # Reusable UI components (Navbar, Footer, etc.)
├── pages/           # Main page layouts
├── sections/        # Modular page sections (Hero, About, Portfolio, etc.)
├── router/          # Application routing configuration
└── index.css        # Global styles and Tailwind directives
```
